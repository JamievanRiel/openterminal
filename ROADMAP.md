# Roadmap (post-v1.0.0)

Parked ideas — deliberately not in v1.0.0:

- Chart drawing tools (trendlines, fibs, annotations) and chart image export
- Multi-link groups (A/B/C/D) with per-panel group assignment UI
- Level 2 / depth-of-book where a provider licenses it
- Options: greeks calculators, strategy builder, historical IV
- Portfolio: lots/tax view, dividends reinvestment tracking, benchmarks beyond SPY
- Backtesting the screener; scheduled screen runs with alert on new matches
- Cross-machine sync of workspaces/notes (end-to-end encrypted)
- Mobile/companion read-only view
- Additional providers (IEX Cloud successor, Databento, EODHD) behind the same router
- Signed + notarized builds with working auto-update feeds; Linux ARM builds
